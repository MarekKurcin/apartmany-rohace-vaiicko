# Apartmány pod Roháčmi

Webová aplikácia pre správu ubytovaní a atrakcií v oblasti Roháčov.
Semestrálna práca z predmetu VAII (FRI UNIZA, 2025/2026).

## Požiadavky

- Docker Desktop (Windows/Mac) alebo Docker Engine (Linux)
- Git

## Inštalácia a spustenie

```bash
git clone https://github.com/MarekKurcin/apartmany-rohace-vaiicko
cd apartmany-rohace-vaiicko/docker
docker-compose up -d
```

Aplikácia bude dostupná na: http://localhost
Adminer (správa DB): http://localhost:8080

### Zastavenie

```bash
docker-compose down
```

## Technológie

PHP 8, Vaiicko Framework (MVC), MariaDB, Bootstrap 5, JavaScript, Docker
